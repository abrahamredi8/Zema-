# ZemaVoice lip-sync prototype — cartoon + realistic character rigs

**Status: runnable audio-to-animation-data prototype, not photorealistic lip-sync.**

## What works
- Convert a 16-bit PCM WAV speech file to frame-by-frame mouth intensity JSON using only NumPy.
- Export coarse mouth shapes and `jawOpen` / `mouthClose` blendshape weights.
- Apply the animation in Blender to either a **3D cartoon** or **realistic rigged** character, provided its mesh has a `jawOpen` shape key.
- Language independent: accepts Amharic speech WAV as input.

## Limitations
- Audio energy **does not identify Amharic phonemes or visemes**. It follows loudness, not exact mouth articulation.
- Realistic human **video** lip-sync, face tracking, and image/video modification are **not implemented**.
- No video is generated by the Python CLI; Blender rendering is a separate step.
- The existing experimental TTS model is not a production-quality Amharic voice engine.

## Run
```bash
pip install numpy
python independent_engine/lipsync/audio_to_animation.py my_amharic_audio.wav --fps 25 --output zemavoice_lipsync.json
```
For MP3 or non-PCM WAV, first convert with:
```bash
ffmpeg -i input.mp3 -ac 1 -ar 16000 -c:a pcm_s16le my_amharic_audio.wav
```

## Blender
Open `blender_apply_animation.py`, edit `TIMELINE_JSON` and `OBJECT_NAME`, and run in Blender's Scripting workspace. Your selected mesh must have a `jawOpen` shape key.
